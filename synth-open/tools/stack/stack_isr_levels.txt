# Interrupt census of the MK66 firmware (original Tracker): every interrupt the image can take and its NVIC level, read from the code.
# stack_margin.py builds the nest of the static stack bound from this file and FAILS when it no longer matches the image or the sources.
#
# Levels are value>>4 of the 8 bit priority (0 = strongest). K66 implements the top 4 bits only (interruptsConfig.h: value2priority).
# mk20dx128.c:792 sets every NVIC priority to 128 (level 8) at reset, a peripheral that nobody re-prioritises stays at level 8.
#
#   isr NAME LEVEL WALKER_REGEX [vec=RAWSYMBOL_REGEX | ram]   # where the level and the enable come from
#       an interrupt that runs. LEVEL is N, or N,usb_audio=M when the level depends on the USB audio feature (the nest is built for both
#       modes and the gate takes the worse row). WALKER_REGEX is the demangled root name for stack_depth.py. vec= says the handler sits in
#       the flash vector table (the census compares it with the image), ram says it is attached at run time (attachInterruptVector or
#       DMAChannel::attachInterrupt writes _VectorsRam), the census then only requires that the function exists
#   off NAME RAWSYMBOL_REGEX                                  # a flash vector with a handler that nothing enables, with the reason
#   src COUNT PATH                                            # source census: number of lines that set a priority, enable an interrupt or write a vector
#       (NVIC_SET_PRIORITY, NVIC_ENABLE_IRQ, EnableIRQ, attachInterrupt, attachInterruptVector, setInterruptPriority, SCB_SHPR, _VectorsRam[]=,
#       .priority( ) per file under platforms/mk66, core, synth-open, util (build dirs, tools/ and ui_shot/ left out). A new call site, a new file
#       or a changed count fails the gate: read the change, add or fix the isr/off row above, then `stack_margin.py --census-print` prints the new src rows
#
# Fault handlers (fault_isr and its aliases, the DebugMonitor stub) never nest below a running ISR in a way that adds to the bound: they spin or reset.
# Reset (vector 1) and the initial SP (vector 0) are not interrupts. An alias of unused_isr is the default and needs no row.
