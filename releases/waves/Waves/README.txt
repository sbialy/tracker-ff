/Waves: single cycle waves for the synth engines that play wave files (ALCO Wave mode: A File and B File).

This folder holds a curated set of AKWF-FREE waves, flat, with the AKWF names (the name is what the parameter shows).
The full set (4,358 waves in 65 folders) is at https://github.com/KristofferKarlAxelEkstrand/AKWF-FREE
Copy any of its .wav files here, or into one folder level below /Waves, and they show up in the file list (sorted by path).
